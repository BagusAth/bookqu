# Customer components

The booking shell provides business identity, branding tokens, a contextual back link, WhatsApp help, and print styles. Views pass display data from the server.

| Component | Use |
|---|---|
| `x-customer.page-header` | One page heading and an optional description |
| `x-customer.summary` | A panel for booking items, an optional details slot and a formatted total |
| `x-customer.stepper` | Number input with named decrement and increment buttons |
| `x-customer.date-strip` | Server-prepared dates with Alpine selection and an optional current date |
| `x-customer.time-grid` | Server-prepared times rendered from an Alpine collection |
| `x-customer.status` | Status, with a prepared label and tone |
| `x-customer.help-link` | An optional WhatsApp link prepared in PHP |
